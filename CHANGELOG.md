# @sandeep-jaiswar/ui

## 0.1.0

### Minor Changes

- Initial release of the zero-dependency UI component library!

  Features:

  - **Pure CSS Tokens**: A robust design system built strictly with CSS Custom Properties.
  - **21 Zero-Dependency Components**: Extracted all runtime dependencies like TailwindCSS to provide drop-in components that are completely framework agnostic.
  - **CLI Support**: Included `npx @sandeep-jaiswar/ui add <component>` CLI tool to copy and paste components natively into projects.
